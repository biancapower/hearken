# Hearken

Hearken is a self-hosted podcast player for your own audio and feeds: a small Rails server holds your library, queue and listening history, and your phone installs the player as a web app. It is built for people who learn from what they listen to, with a transcript that follows along beside the controls and notes pinned to the moment they were taken.

This Hearken is an independent open-source project. It is not affiliated with Hearken, Inc. or its newsroom software.

The name is read as *hear* + *ken*, where ken is a person's range of knowledge or understanding: what you come to know by listening. That reading is the intended sense rather than the word's history, which runs back to Old English *heorcnian*, kin to *hark*.

## Status

Pre-0.1.0. There is no app to run yet. Release 0.1.0 is a player that can replace a phone podcast app for the maintainer's own feeds, served over a private network.
